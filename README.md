# 🎮 Pedra, Papel ou Tesoura

Projeto desenvolvido como desafio prático do curso Full Stack da Digital College.

## 📚 Sobre o projeto

Este projeto consiste em um jogo simples de Pedra, Papel ou Tesoura, onde o usuário escolhe uma jogada e o computador gera uma escolha aleatória para definir o vencedor da partida.

O objetivo do desafio foi praticar:

- Estruturação HTML
- Estilização com Tailwind CSS
- Manipulação do DOM
- Eventos com JavaScript
- Lógica condicional
- Funções em JavaScript

---

## 🚀 Tecnologias utilizadas

- HTML5
- Tailwind CSS
- JavaScript

---

## 🎯 Funcionalidades

- Escolha entre pedra, papel ou tesoura
- Jogada aleatória do computador
- Exibição do resultado da partida
- Interface simples e responsiva

## 🧠 Aprendizados

Durante o desenvolvimento deste projeto, foram praticados conceitos importantes como:

- Manipulação de elementos HTML com JavaScript
- Uso de funções
- Condicionais (`if / else`)
- Arrays
- Geração de números aleatórios
- Organização de estrutura semântica
